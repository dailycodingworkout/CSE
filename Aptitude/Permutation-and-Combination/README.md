## Key Formulas Quick Reference

| Formula | Expression |
|---------|-----------|
| Factorial | n! = n × (n−1) × ... × 1 |
| Permutation | P(n,r) = n! / (n−r)! |
| Combination | C(n,r) = n! / [r! × (n−r)!] |
| Circular Permutation | (n−1)! |
| Necklace | (n−1)! / 2 |
| With Replacement | n^r |
| Multinomial | n! / (n₁! × n₂! × ... × nₖ!) |
| Stars & Bars | C(n+r−1, r−1) |
| Derangement | D(n) = n! × Σ(−1)^k / k! |
| Surjection | Σ(−1)^k × C(r,k) × (r−k)^n |
