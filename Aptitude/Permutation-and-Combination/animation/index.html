P & C Masterclass

1. Fundamental Counting Principle

The DNA of every counting problem — master this, master everything.

3D Animation — Multiplication Principle

The Atomic Truth

Counting = Choosing at each independent stage.

Every counting problem reduces to: How many choices at each step, and are the steps independent?

Multiplication Principle (AND)

If task A can be done in m ways and then task B can be done in n ways, total ways = m × n.

Multiplication Principle Total = n₁ × n₂ × n₃ × … × nₖ

Why multiply? Think of it as a tree. Each branch at stage 1 spawns n₂ branches at stage 2. The total number of leaf nodes (complete paths) = product of branches at each level.

Example — Shirt & Pants

You have 3 shirts and 4 pants. How many outfits?

Each shirt can pair with any of 4 pants. Total = 3 × 4 = 12 outfits

Addition Principle (OR)

If task A can be done in m ways or task B can be done in n ways (mutually exclusive), total ways = m + n.

Addition Principle Total = n₁ + n₂ + n₃ + … + nₖ  (when cases are mutually exclusive)

Why add? When you choose one or the other (not both), you are counting separate non-overlapping buckets. Just add the bucket sizes.

Example — Travel

3 trains or 2 flights from A to B. Total ways = 3 + 2 = 5 ways

GATE Trap

AND vs OR confusion: "Do task A and then task B" → multiply. "Do task A or task B" → add. If tasks overlap (not mutually exclusive), use inclusion-exclusion.

Edge Case

Dependent stages: If choices at stage 2 depend on stage 1, the multiplication still works — but n₂ may vary per branch. Sum over all branches: Σ (choices at stage 2 given stage 1 choice).

2. Factorial — The Building Block

Every formula in P&C is built from factorials. Understand it deeply.

3D Animation — Factorial Cascade

What is n! ?

n! (read "n factorial") = the number of ways to arrange n distinct objects in a line.

Factorial Definition n! = n × (n−1) × (n−2) × … × 2 × 1

Why does this formula work?

Imagine placing n distinct balls into n slots one by one:

  • Slot 1: n choices (any ball)
  • Slot 2: n−1 choices (one used)
  • Slot 3: n−2 choices
  • …continue until…
  • Slot n: 1 choice (last ball remaining)

By Multiplication Principle: total = n × (n−1) × … × 1 = n!

Example

Arrange {A, B, C}: 3! = 3 × 2 × 1 = 6

All arrangements: ABC, ACB, BAC, BCA, CAB, CBA

Special Values & Properties

Key Facts 0! = 1  |  1! = 1  |  n! = n × (n−1)!

Why is 0! = 1? There is exactly 1 way to arrange zero objects — do nothing. Also, the recurrence n! = n × (n−1)! requires 0! = 1 for consistency when n=1: 1! = 1 × 0! ⇒ 0! = 1.

Speed Trick — Trailing Zeros

Number of trailing zeros in n! = ⌊n/5⌋ + ⌊n/25⌋ + ⌊n/125⌋ + …

Example: 100! has ⌊100/5⌋ + ⌊100/25⌋ = 20 + 4 = 24 trailing zeros.

Edge Case

Negative integers have no factorial. Factorials grow super-exponentially: 20! ≈ 2.4 × 1018. In GATE, you rarely compute beyond 10!.

3. Permutations (nPr)

Arrangement matters — the order-sensitive count.

3D Animation — Selecting & Arranging

The Atomic Truth

Permutation = Selection + Arrangement.

Derivation from First Principles

Choose r items from n distinct items and arrange them:

  • Position 1: n choices
  • Position 2: n−1 choices
  • …
  • Position r: n−r+1 choices
Permutation Formula P(n, r) = n × (n−1) × … × (n−r+1) = n! / (n−r)!

Why n!/(n-r)! ? We start with all n! arrangements but the last (n-r) positions are irrelevant (we only pick r). Dividing by (n-r)! cancels the unwanted tail.

Example — Gold, Silver, Bronze

8 athletes, award top 3 medals. How many outcomes?

P(8,3) = 8 × 7 × 6 = 336

Example — Word Arrangements

How many 4-letter "words" from {A, B, C, D, E} (no repetition)?

P(5,4) = 5 × 4 × 3 × 2 = 120

Permutation of ALL n objects

When r = n: P(n,n) = n! (arrange everything).

GATE Trick — Constraint First

When a problem has constraints ("A must be before B", "vowels together"), always handle the constrained elements first, then fill the rest.

Edge Cases

P(n,0) = 1 (one way to pick nothing). P(n,n) = n!. P(n,r) = 0 if r > n.

4. Combinations (nCr)

Selection without arrangement — order doesn't matter.

3D Animation — Grouping without Order

The Atomic Truth

Combination = Permutation ÷ (internal arrangements).

Derivation — Why divide by r! ?

P(n,r) counts every ordered selection. But if order doesn't matter, each group of r items has been counted r! times (once for each internal arrangement).

Combination Formula C(n, r) = P(n, r) / r! = n! / [r! × (n−r)!]

Analogy: Permutation is like picking a team and assigning jersey numbers. Combination is just picking the team — no jerseys.

Example — Committee

Choose 3 people from 10 for a committee.

C(10,3) = 10! / (3! × 7!) = (10 × 9 × 8) / (3 × 2 × 1) = 120

Key Properties

Symmetry & Special Values C(n,r) = C(n, n−r)  |  C(n,0) = C(n,n) = 1  |  C(n,1) = n

Why symmetry? Choosing r items to include is the same as choosing (n-r) items to exclude.

Speed Trick

Always compute C(n,r) using the smaller of r and n-r. C(100,98) = C(100,2) = (100 × 99)/2 = 4950. Don't compute 98!.

GATE Trap

"Select" vs "Arrange": If the problem says "choose", "select", "committee", "group" → Combination. If it says "arrange", "order", "rank", "sequence" → Permutation.

5. Circular Permutations

When the "starting point" doesn't matter — round tables, necklaces, rings.

3D Animation — Circular Arrangement

The Atomic Truth

Fix one, arrange the rest.

Derivation

In a line, n objects have n! arrangements. In a circle, rotations of the same arrangement look identical. There are n rotations per arrangement.

Circular Permutation Circular arrangements = n! / n = (n−1)!

Why (n-1)!? Fix one person's seat to break rotational symmetry. The remaining (n-1) people arrange in (n-1)! ways.

Example — Round Table

Seat 5 people around a circular table.

Arrangements = (5−1)! = 4! = 24

Necklace / Bracelet (Reflections)

If the arrangement can also be flipped (like a necklace), divide by 2:

Necklace Formula Necklace arrangements = (n−1)! / 2
Example — Bead Necklace

Arrange 6 different beads on a necklace.

= (6−1)! / 2 = 120 / 2 = 60

GATE Trap

Table vs Necklace: Round table → (n-1)!. Necklace/keyring → (n-1)!/2. The question must explicitly allow flipping for the /2 to apply.

6. Permutations with Repetition

When some objects are identical — divide out the duplicates.

3D Animation — Identical Objects

Case 1: Repetition Allowed (with replacement)

Fill r positions from n types, each type unlimited.

Permutation with Replacement n × n × … (r times) = nr
Example — PIN Code

4-digit PIN from digits {0–9}. Each position: 10 choices.

Total = 104 = 10,000

Case 2: Identical Objects (Multinomial)

Arrange n objects where some are identical.

Multinomial Permutation n! / (n₁! × n₂! × … × nₖ!)

Why divide? Swapping identical objects doesn't create a new arrangement. Each group of nᵢ identical items has nᵢ! internal swaps that look the same.

Example — MISSISSIPPI

Arrange the letters of MISSISSIPPI (11 letters: M×1, I×4, S×4, P×2).

= 11! / (1! × 4! × 4! × 2!) = 39916800 / (1 × 24 × 24 × 2) = 34,650

Speed Trick

For MISSISSIPPI-type problems, identify repeated letters first. Count: sum of all repetitions must equal total letters (sanity check).

Edge Case

If all objects are identical, arrangements = n!/n! = 1. Makes sense — you can't distinguish any arrangement.

7. Combinations with Repetition (Stars & Bars)

Distributing identical items into distinct groups — the most elegant trick in P&C.

3D Animation — Stars and Bars

The Atomic Truth

Turn distribution into a string of stars and bars.

Problem Setup

Distribute n identical items into r distinct groups (each group can get 0 or more).

Derivation

Represent items as stars (★) and separators as bars (|). We need n stars and (r−1) bars. Example: distributing 5 identical candies to 3 children.

★★|★★★| → (2, 3, 0). Total symbols = n + r − 1. Choose which (r−1) are bars:

Stars and Bars Formula C(n + r − 1, r − 1) = C(n + r − 1, n)
Example — Candy Distribution

Distribute 5 identical candies to 3 children (each can get ≥ 0).

C(5+3−1, 3−1) = C(7, 2) = 21

21 ways

Variant: Each group gets ≥ 1

Give 1 to each group first, then distribute the remaining (n − r) freely:

At Least 1 Each C(n − 1, r − 1)
Example — At Least One

Distribute 5 identical candies to 3 children, each gets ≥ 1.

C(5−1, 3−1) = C(4, 2) = 6 ways

GATE Trick

Equation Solutions: Number of non-negative integer solutions of x₁+x₂+…+xₖ=n is exactly C(n+r-1, r-1). This is the same as Stars & Bars.

8. Derangements

When nothing goes to its original position — the "chaos" count.

3D Animation — Derangement

The Atomic Truth

A derangement is a permutation with zero fixed points.

Formula & Derivation

D(n) = number of permutations of n elements where no element appears in its original position.

Derangement Formula D(n) = n! × [1 − 1/1! + 1/2! − 1/3! + … + (−1)n/n!]

Where does this come from? Apply Inclusion-Exclusion. Let Aᵢ = set of permutations where element i is fixed. Then:

  • |Aᵢ| = (n-1)!, |Aᵢ ∩ Aⱼ| = (n-2)!, etc.
  • D(n) = n! − C(n,1)(n-1)! + C(n,2)(n-2)! − … = n! × Σk=0 to n (−1)k/k!

Quick Values

D(1)=0, D(2)=1, D(3)=2, D(4)=9, D(5)=44

Example — Hat Check

4 people check hats. In how many ways can hats be returned so nobody gets their own?

D(4) = 4!(1 − 1 + 1/2 − 1/6 + 1/24) = 24 × (3/8) = 9

Speed Trick

Recurrence: D(n) = (n−1)[D(n−1) + D(n−2)]. Use this for small n instead of the summation.

Approximation

For large n, D(n) ≈ n!/e (where e ≈ 2.71828). Round to nearest integer. Probability of a derangement → 1/e ≈ 0.3679.

9. Inclusion-Exclusion Principle

Count the whole, subtract overlaps, add back over-subtractions — recursively.

3D Animation — Overlapping Sets

The Atomic Truth

Don't double count. Don't double subtract.

Two-Set Formula

Inclusion-Exclusion (2 sets) |A ∪ B| = |A| + |B| − |A ∩ B|

Three-Set Formula

Inclusion-Exclusion (3 sets) |A ∪ B ∪ C| = |A|+|B|+|C| − |A∩B| − |A∩C| − |B∩C| + |A∩B∩C|

General Formula

General Inclusion-Exclusion |A₁ ∪ … ∪ Aₙ| = Σ|Aᵢ| − Σ|Aᵢ∩Aⱼ| + Σ|Aᵢ∩Aⱼ∩Aₖ| − …
Example — Divisibility

How many integers from 1 to 100 are divisible by 2 or 3?

|div by 2| = 50, |div by 3| = 33, |div by 6| = 16

Answer = 50 + 33 − 16 = 67

Example — Euler's Totient

φ(n) = n × ∏(1 − 1/p) for each prime factor p of n. This IS inclusion-exclusion applied to "numbers NOT coprime to n".

GATE Trick — Complement Counting

At least 1 = Total − None. Often easier to count what you don't want and subtract from total.

10. Pascal's Triangle & nCr Identities

The golden structure hiding inside every combination formula.

3D Animation — Pascal's Triangle

Pascal's Identity

Pascal's Rule C(n, r) = C(n−1, r−1) + C(n−1, r)

Why? Consider element x. Either x is in your selection (then choose r-1 from remaining n-1) or x is not (choose all r from remaining n-1).

Essential Identities for GATE

Sum of Row C(n,0) + C(n,1) + … + C(n,n) = 2n

Why 2n? Each element is either in or out of a subset → 2 choices per element → 2n subsets total.

Alternating Sum C(n,0) − C(n,1) + C(n,2) − … = 0  (for n ≥ 1)
Vandermonde's Identity C(m+n, r) = Σ C(m, k) × C(n, r−k)  for k=0 to r

Why? Choose r items from two groups (m items + n items). If k come from group 1, then r−k come from group 2.

Hockey Stick Identity C(r,r) + C(r+1,r) + … + C(n,r) = C(n+1, r+1)
GATE Trick

Binomial Theorem: (1+x)n = Σ C(n,k) xk. Set x=1 to get sum=2n. Set x=−1 to get alternating sum=0. Differentiate/integrate for advanced identities.

11. Distribution & Partition Problems

The 4 cases every exam loves: identical/distinct items into identical/distinct boxes.

3D Animation — Distribution Matrix

The Distribution Matrix

Every distribution problem falls into one of these 4 categories:

Case 1: Distinct items → Distinct boxes (functions)

Each item independently chooses a box. Total = rn (r boxes, n items).

If at most 1 per box: P(r, n) = r!/(r-n)!

Case 2: Identical items → Distinct boxes (Stars & Bars)

C(n+r-1, r-1) ways. Already covered in Stars & Bars.

Case 3: Distinct items → Identical boxes (Stirling numbers)

Uses Stirling numbers of the second kind S(n,r) = partitions of n items into exactly r non-empty groups.

Total (allowing empty boxes) = S(n,1) + S(n,2) + … + S(n,r) = Bell number B(n) if r ≥ n.

Case 4: Identical items → Identical boxes (Integer partitions)

Number of ways to write n as sum of at most r positive integers. No closed formula — enumerate or use generating functions.

Onto Functions (Surjections)

Surjection Count Onto(n → r) = Σ (−1)k C(r,k) (r−k)n  for k=0 to r

This is Inclusion-Exclusion applied to distribution: subtract cases where ≥1 box is empty.

GATE Trick

Quick classifier: Ask two questions. (1) Are items same or different? (2) Are boxes same or different? This immediately tells you which formula to use.

12. GATE / ESE / PSU / BANK — Tricks & Edge Cases

The master arsenal for exam-day speed and accuracy.

3D Animation — Strategy Overview

Technique 1: Complement Counting

P(at least 1) = 1 − P(none). Use when "at least" appears in the question.

Example

Probability that at least one head in 3 coin tosses?

= 1 − P(no heads) = 1 − (1/2)³ = 1 − 1/8 = 7/8

Technique 2: Fix & Count

For "relative position" problems: fix the constrained elements, then count the rest.

Example

Arrange ABCDE such that A comes before B (not necessarily adjacent).

By symmetry, A before B in exactly half the arrangements: 5!/2 = 60

Technique 3: Gap Method

For "no two adjacent" problems: first place the non-restricted items, then use the gaps.

Example

Arrange 5 boys and 3 girls so no two girls are adjacent.

Place 5 boys: 5! ways. This creates 6 gaps (_B_B_B_B_B_). Choose 3 of 6 gaps for girls: C(6,3). Arrange girls: 3!.

Total = 5! × C(6,3) × 3! = 120 × 20 × 6 = 14,400

Technique 4: Treat-as-One (Bundling)

For "together" constraints: bundle the required group into a single super-element.

Example

Arrange ABCDE with A and B always together.

Bundle {AB} as one unit → 4 units to arrange: 4! = 24. Internal arrangement of A,B: 2!.

Total = 4! × 2! = 48

Technique 5: Bijection (Counting in Disguise)

Map a hard counting problem to an equivalent easier one.

Example — Lattice Paths

Paths from (0,0) to (m,n) using only right (R) and up (U) steps?

Each path = a string of m R's and n U's = arrangement of identical objects.

Answer = C(m+n, m) = C(m+n, n)

Technique 6: Generating Functions (Advanced)

Coefficient of xr in a generating function gives the count.

Example

Ways to make change of 10 using coins of 1, 2, 5:

Find coefficient of x10 in (1+x+x²+…)(1+x²+x⁴+…)(1+x⁵+x10+…)

Common Edge Cases in GATE

Edge Case Checklist
  • n=0: C(0,0)=1, P(0,0)=1, 0!=1, D(0)=1
  • r > n: C(n,r)=0, P(n,r)=0
  • All identical: Only 1 arrangement
  • Overcounting symmetry: Divide by symmetry group size
  • "At least" / "at most": Often easier via complement
  • With/without replacement: Read the question twice

5-Second Sanity Checks

Verification Heuristics
  • C(n,r) must be a positive integer
  • C(n,r) ≤ nr / r! (rough upper bound)
  • P(n,r) ≥ C(n,r) always
  • Total subsets of n elements = 2n (includes empty set)
  • If answer seems too large, check if you forgot to divide by symmetry
  • If answer seems too small, check if you accidentally used combination instead of permutation

GATE Previous Year Pattern

High-Frequency Topics
  • Permutations of words with repeated letters (MISSISSIPPI-type)
  • Circular arrangements with constraints
  • Stars & Bars / integer solutions
  • Derangements
  • Committee formation with constraints (at least 1 woman, etc.)
  • Lattice paths and grid problems
  • Surjections (onto functions)
